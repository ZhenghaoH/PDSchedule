# FlexPD分离调度功能效果展示操作

## 工作流程

```
--------------------------------------------------
| [Client] -> [Scheduler] -> [Proxy] -> vLLM实例 |
--------------------------------------------------
```

- Client以http请求格式发起推理服务，并发送给Scheduler
- Scheduler收到请求后会解析请求信息并构建Request类，通过调度决策，Scheduler决定请求转发给哪个推理池（在本实验中是在8081和8082两个P池中选一个，理论上也会同D池，但本实验中D池只开了一个）
- c推理池Proxy接收到请求后，根据本地策略转发请求给池内具体的实例（在本实验中，每个P池只放了一个实例，所以看不出来选择，D池有两个实例，能根据PD配对进行选择，但视频中看不出来）
- Proxy将请求送入vllm实例并等待回复

## 快速开始

### 1 启动环境

在1个窗口新建docker容器

```bash
sudo docker run --gpus all --shm-size=16g -it --network host -v /home/zkgy/vLLM/workspace:/workspace/workspace --name test vllm-5090:latest
```

在其他9个窗口启动docker容器

```bash
sudo docker exec -it test /bin/bash
```

在docker容器环境中修改vLLM部分源码

```bash
cp /workspace/workspace/FlexPD/instance/vLLM/mooncake_pipe.py /workspace/vllm/vllm/distributed/kv_transfer/kv_pipe/mooncake_pipe.py 

cp /workspace/workspace/FlexPD/instance/vLLM/simple_buffer.py /workspace/vllm/vllm/distributed/kv_transfer/kv_lookup_buffer/simple_buffer.py
```
