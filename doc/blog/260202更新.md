# FlexPD 系统更新日志

## 文件层间更新

### 1. 新增文件

- `instance/perception/compute_metric_h.py`：实现了 `ThroughputMonitor` 类，用于计算滑动窗口内的吞吐量，支持高频采样和分别计算 prompt 与 generation 的吞吐量

## 功能增强

### 1. 吞吐量监控
- 实现了 `ThroughputMonitor` 类，用于计算滑动窗口内的平均吞吐量
- 实现了 `SingleVLLMMonitor` 和 `MultiVLLMMonitor` 类，用于监控多个 VLLM 实例
- 实现了 `profile_throughput.py` 用于生成测试 prompts 并测量吞吐量
- 高频采样：使用 0.1 秒的采样间隔
- 滑动窗口：采用 2 秒的滑动窗口计算平均吞吐量
- 分别计算 prompt 和 generation 的吞吐量
- 使用线程锁保护共享数据，确保线程安全

### 2. 网络带宽监控
- 实现了 `get_interface_metrics` 函数，根据 IP 地址获取对应网卡的当前带宽指标
- 实现了 `calculate_available_bandwidth` 函数，计算剩余可用带宽
- 在网络链路更新时，使用实际可用带宽替代配置值

### 3. 负载归一化
- 根据 `max_prompt_throughput` 对 Prefill 节点的负载进行归一化
- 确保不同性能的节点负载具有可比性

### 4. 调度优化
- 在 PSO 调度器中，增强了适应度计算，考虑了节点的负载情况
- 实现了节点能力排名的计算，基于算力/带宽进行排序
- 使用百分位排名，确保能力相同的节点得到公平对待

### 5. 高频同步
- 将轮询上报任务时间从 1.0 改为 0.1
- 提高了系统状态的实时性

### 6. 负载计算
- Prefill 负载：基于实例的 prompt 吞吐量计算
- Decode 负载：基于实例的运行中和等待中的请求数计算

### 7. 异常处理
- 在 `compute_metric_h.py` 中，设置了网络请求超时处理，防止卡死
- 当无法获取指标时，使用默认值 0
