# Runtime flows

| Flow | Participants | Request/model types and identifiers | Entrypoints | Observable outputs | Failure/fallback boundaries | Tests/demos | Not yet implemented |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Inference and pair selection | Client → Controller → P/D Gateways → P/D Instances → vLLM | `BaseRequest`, `Prompt`, `Service`, `Task`, `Request_ID` | Controller `/v1/chat/completions` or `/v1/completions` | Request page, Gateway schedule/timing logs, response stream | Missing compatible Pools fails; tokenizer can use character-count fallback; single compatible pair bypasses strategy | [single routing](../../test/test_single_gateway_routing.py), [quick start](../quickstart_v1.md) | Full OpenAI API coverage and unified trace |
| Registration and updates | Instance → Gateway → Controller | `report_label`, Pool ID, role, Connector descriptor | `/instance/register`, `/instance/update`, Pool registration/update | Gateway and Controller logs and state | A registered Instance becomes online on update; 404 update triggers registration attempt; address/descriptor mismatch can reject | [registration](../../test/test_runtime_instance_registration.py) | Registration is not proof that engines are ready |
| Resource state | vLLM/NVML/host → Instance → Gateway → Controller | Instance metrics, Pool load, network link and snapshot version | periodic reporting | Resource logs and CLI | Missing metrics may default to zero; link values may be estimates; inspect [field audit](../resource_state_metrics.md) | [observability](../../test/test_gateway_observability.py), [decode load](../../test/test_decode_pool_load.py) | Cross-process measurement provenance contract |
| NIXL handoff | P Gateway, P engine, D Gateway, D engine | Connector session, `connector_context`, `kv_transfer_params`, request ID | Gateway Connector/session and inference paths | Gateway logs, vLLM transfer metrics | Missing Prefill transfer parameters fails; matching descriptors do not prove bytes moved | [protocol](../../test/test_connector_protocol.py), [NIXL integration](../integrations/nixl.md) | Automatic validation of physical transfer by Controller |
| LMCache shared backend | Gateways, Instances, serving engines and shared backend | `backend`, `namespace`, `config_fingerprint` | same application inference path | serving/backend logs and cache-specific metrics | Identity checks do not configure or verify storage and reuse | [protocol](../../test/test_connector_protocol.py), [LMCache](../integrations/lmcache.md) | Complete validated serving recipe for every LMCache version |
| Profiling and prediction | Real vLLM, offline profiling tools, Controller/Gateway | TTFT/TPOT measurements and local model files | [profile tools](../../profile/README.md), Gateway predictor flags | artifacts, calibration/validation reports, startup logs | Missing calibration can trigger fallback; files are not packaged | [profiler](../../test/test_distserve_lm_profiler.py), [SLO](../slo.md) | Guaranteed prediction accuracy across models/topologies |

The Gateway queues and reservations are local scheduling state. HTTP response completion and physical KV transport have different boundaries; see [observability](../architecture/observability-v1.md).
